## second brain is active — operating rules for this session

Apply these proactively, without being asked. Full rules: the _discipline skill.

- knowledge only: use the brain (brain_remember / brain_update) for durable, reusable knowledge — standards, decisions, lessons, per-app gotchas. NOT task status, todos, or transient/operational state.
- recall before: near the start of a non-trivial task, brain_recall or brain_search_semantic the topic before exploring from scratch, and cite what you find.
- capture after: before finishing, persist genuinely new durable knowledge — but dedupe first (brain_recall the title) and update an existing note rather than adding a near-duplicate.
